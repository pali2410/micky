Micky uses the pinned DeepSeek Harness 0.2.0-rc.2 SDK profile over a local stdio pipe. Install reproducibly with `npm ci` in this directory. Node 24 is required for this runtime; Electron's bundled Node does not load it.

`micky.patch.yml` connects the installed Ollama planner and conversation models. Planning is enabled with `BOPS_PLANNER_ENGINE=deepseek`. Model-generated JSON is validated by Micky before its Windows executor acts. Existing deterministic WhatsApp/file/app operations remain in that executor. Runtime failure falls back to the local structured planner; mutation requests are never retried by a provider retry policy.

The released rc.2 protocol settles a turn through session.status notifications. Newer source documentation describes session/wait, which this pinned release does not expose. Each planning request has an independent SDK session, persisted under E:\micky\.data\deepseek. Cancellation shuts down the owned runtime.

The default action planner remains the local structured planner. `BOPS_REASONING_ENGINE=deepseek` connects DeepSeek to consult actions and one bounded recovery attempt when a task repeats without progress. DeepSeek's optional primary planning mode remains experimental: JSON grammar alone does not guarantee a useful action or correct completion. This does not enable every optional upstream plugin or port all platform-specific features. Micky's Windows Whisper/Kokoro engine replaces the native call transport through Electron IPC; macOS speech binaries are not used. OpenMausBot provider components and their license notices are in vendor/openmaus.
